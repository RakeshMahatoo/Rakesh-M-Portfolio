Overview

Rakesh-M-Portfolio is a modern React developer portfolio template optimized for speed, customization, and visual appeal. Built with Vite, Tailwind CSS, and ESLint, it provides a streamlined setup for creating engaging, maintainable personal websites. The core features include:

🛠️ Fast Development Workflow: Utilizes Vite with React, supporting Hot Module Replacement (HMR) and flexible plugin options for rapid iteration.
🎨 Custom Styling & Animations: Extends Tailwind CSS with unique animations, gradients, and visual effects to craft dynamic interfaces.
🔍 Code Quality & Best Practices: Enforces consistent, error-free code with ESLint configured for React and JavaScript.
🧩 Modular Architecture: Centralized constants and reusable components facilitate scalability and maintainability.
🌟 Visual Enhancements: Incorporates animated blobs and interactive UI elements to elevate user engagement.

Installation

Build Rakesh-M-Portfolio from the source and install dependencies:

Install the dependencies:

Using npm:
